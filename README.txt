FOREVER WITH MUSNA — PINK GLASSMORPHISM EDITION

1. Open index.html in Chrome to preview.
2. Personalize the three photos by placing images in an images folder and changing:
   const memoryPhotos=["images/photo1.jpg","images/photo2.jpg","images/photo3.jpg"];
3. Edit the sample captions, secret messages, and birthday letter in index.html.
4. Optional music: add music/song.mp3 and set const musicSource="music/song.mp3";
   Audio starts after the visitor taps the music button. Use music you have permission to share.
5. Deploy the whole folder (index.html plus images/music folders) using https://app.netlify.com/drop
6. Test the generated link on a phone before sending it.
The URL is not password-protected; don't upload sensitive photos or private details.
